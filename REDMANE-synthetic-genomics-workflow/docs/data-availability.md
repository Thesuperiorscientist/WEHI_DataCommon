# Data Availability

## Input Data

The project used Genome in a Bottle (GIAB) HG005 whole-genome sequencing data.

The data consisted of paired-end sequencing reads.

## Generated Data

The workflow generated:

- FASTQ files
- BAM files
- Sorted BAM files
- BAI index files
- BCF files
- VCF files

## GitHub Repository

Large genomic datasets are intentionally excluded from this repository because of their size.

This repository contains documentation and metadata describing the datasets and workflow.

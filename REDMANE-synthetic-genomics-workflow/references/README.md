
# References

## Genome in a Bottle

Genome in a Bottle (GIAB) was used as the source of the HG005 sequencing data.

## Reference Genome

GRCh38/hg38 was used as the reference genome, with chromosome 22 selected for the final computational workflow.

## Software

The workflow used:

- BWA
- Samtools
- BCFtools
- Python
- Jupyter Notebook
- Bash
- WSL / Ubuntu

Software versions used during development are documented in the technical diary.
